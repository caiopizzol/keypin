# Agents

## Writing docs

README, `docs/` and `skills/keypin/SKILL.md` stay short. Before adding a line, ask whether a reader would get
stuck without it.

- Add only what someone needs to do the next step or avoid a mistake.
- Say each thing once, where a reader looks for it. Link instead of repeating.
- Don't explain what an error message or `--help` already tells the reader.
- Don't document edge cases in the README; keep them in `docs/`, or leave them to the error message.
- When you add a line, look for one to remove. A docs change should rarely grow the file.
- Follow the voice in [BRAND.md](BRAND.md): plain, short sentences, no emphasis or filler.
