# Security

Only the latest release gets security fixes.

## Reporting a vulnerability

Report it privately: on this repository's **Security** tab, select **Report a vulnerability**. Don't open a public
issue or pull request about it.

Include what you found, how to reproduce it and what an attacker could do with it. You'll get a reply in that report.

## Scope

In scope: the `keypin` CLI and the packages in this repository, such as a key value written to disk or to output,
published to the wrong account or destination, or read without the vault's approval.

Out of scope: weaknesses in 1Password, GitHub, Cloudflare, Bun or other software keypin uses. Report those to their
maintainers.
