Every key, pinned
to its account.

keypin keeps a map of every app key across your projects, then publishes each one to GitHub Actions and Cloudflare Workers. It checks the account before every write and shows you the plan first. Values stay in your vault.

$ bun add -g keypin

Needs Bun 1.4.4 or newer and the 1Password desktop app.
Publishing to Cloudflare works on macOS only for now. Setup is in the README.

01

How it works

01 / MAP

map

Each project lists its keys in a committed keypin.toml: the variable, the vault item, and every place the key is published. It never holds a value. 

# names and places, never values
[vaults.personal]
account = "my.1password.com"
vault = "App Secrets"

[keys.api-token]
env = "API_TOKEN"

[keys.api-token.prod]
vault = "personal"
item = "api prod api token"

[[keys.api-token.prod.publish]]
to = "github-actions"
repo = "acme/api"
02 / RUN

run

Run a command with the project's dev keys in its environment. keypin reads them from 1Password while the command runs and writes them nowhere on disk, so there's no .env to leak. 

$ keypin run -- bun dev
keypin: reading dev values from
  1Password account my.1password.com,
  vault "App Secrets":
  "api dev api token"
  ➜  Local: http://localhost:3000/
03 / PUBLISH

publish

keypin checks each destination is the account the map pins, shows the plan, and waits for you. Receipts let a rerun skip what's already written. 

Account checks:
  ok github-actions:acme/api:…
  ok cloudflare-worker:api-edge:…

Plan for generation 87c5ad3105ddfcc3:
  write github-actions:acme/api:…
    needs approval: first write
  write cloudflare-worker:api-edge:…
    needs approval: first write
Type yes to write: yes
  wrote github-actions:acme/api:…
  wrote cloudflare-worker:api-edge:…
02

Commands

keypin init [folder]
Register a project and write a commented keypin.toml. An existing one stays as it is.
keypin unregister [folder]
Stop listing a project. Its keypin.toml stays.
keypin status [--json]
Every key, its rotation dates and receipts, then problems. Exit 0 means none.
keypin run -- <command>
Run a command with the project's dev keys in its environment.
keypin publish <key-id>
Check accounts, show the plan, then write the key to every destination: GitHub Actions secrets and Cloudflare Worker secrets. A first write or an account change waits for you to type yes; --yes never gives that approval.
